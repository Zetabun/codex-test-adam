# Single Room with Cabinet (WebGL)

This is a self-contained WebGL room demo in a single `index.html` file.

## Run

1. Open `index.html` directly in your browser, or publish it via GitHub Pages.
2. Click and drag on the canvas to look around.

## Controls

- `W` / `S`: move forward/back
- `A` / `D`: strafe left/right
- Mouse: look around (drag always works)
- Pointer lock is attempted when available

## Notes

- Includes a desk area, monitor, trophy cabinet, wall CDs, and minimap.
- Uses directional + point-light shading and semi-transparent glass panels for stronger depth/readability.
- Built-in self-tests run automatically at startup and log results to DevTools.
